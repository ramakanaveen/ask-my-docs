## 📝 Design Principles

1. **Modularity** - Separate concerns, clear interfaces
2. **Scalability** - Design for growth from day one
3. **Security** - Permission checks at every layer
4. **Observability** - Log everything for compliance and debugging
5. **User-Centric** - Rich UX with professional output quality

## 🤖 For AI Assistants

This documentation is designed to help AI coding assistants (Claude Code, Copilot, etc.) understand the system architecture. When working on a specific component:

1. Read the relevant architecture doc first
2. Check the database schema for data models
3. Review the API spec for endpoint contracts
4. Follow the coding standards in `/docs/development/`
